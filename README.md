# Cicuitos-AC
Repositorio de una página web publicada con **GitHub Pages** que centraliza apuntes, recursos técnicos y material académico en formato web y PDF.

## 🌐 Demo
👉 https://Samuel-M-I.github.io/Cicuitos-AC/
## Apuntes

## 📌 Contenido
- Apuntes técnicos organizados por tema
- Documentos en formato **PDF**

## 🛠️ Tecnología
- GitHub Pages

## 🔍 Buscador
El buscador permite localizar contenido dentro del sitio.  
> Nota: la búsqueda depende de la indexación del contenido (ver sección PDF).

## 📄 PDFs
Los archivos PDF están disponibles para descarga directa desde el sitio web.

## 🚀 Despliegue
El sitio está desplegado usando **GitHub Pages** desde la rama:
- `main`
